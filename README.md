# e-plantShopping

## Project Description

e-plantShopping is a React-based online plant shopping application where users can browse different categories of plants, view product details, and add plants to their shopping cart.

## Features

* Attractive landing page.
* Company information section.
* Multiple plant categories.
* Product images, names, and prices.
* Add to Cart functionality.
* Shopping cart with quantity controls.
* Remove products from the cart.
* Automatic total price calculation.
* Redux Toolkit for cart state management.

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Redux Toolkit
